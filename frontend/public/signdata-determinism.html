If yes, a position key can be derived from the wallet alone, and positions close from any device.

Setup

Whatever your wallet is on; filled in from config.json when present. Signing does not touch the chain, so this only has to be a network the wallet will connect to.

A different control message is signed between each one. 1AM refuses a repeat of a payload it has just seen — "Duplicate request, a similar request is already pending" — so the alternation is what makes the repeat reachable at all. Expect roughly twice this many prompts.
